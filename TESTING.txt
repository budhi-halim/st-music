LIMITATIONS
No user recordings were supplied for this revision. The distributed lyric data
is plain and untimed; no test timestamps or generated sample audio are shipped.
The backend's orchestration/validation was tested with a mocked aligner, not a
real downloaded Whisper model. Actual forced-alignment quality and Windows
CUDA setup have NOT been tested here. Run one real recording first as described
in SETUP.txt, then inspect the combined review and listen before batch use.

This execution environment blocks browser URL navigation by administrator
policy. UI checks therefore used in-memory HTML/CSS/JS with mapped synthetic
audio sources and a fixture lyric response, rather than a live HTTP deployment.
No policy settings were changed. This does not verify your Live Server's
range responses, MIME headers, cache behavior or physical device playback.
Physical Android/iOS testing and end-to-end browser service-worker migration
were not performed. The worker retirement assertions use a simulated context.
